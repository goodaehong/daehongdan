# qt_client — 관제 클라이언트 (Qt)

## 📌 개요

- 라즈베리파이 서버에서 센서 · 감지 데이터를 받아 표시하는 데스크톱 관제 화면
- 액추에이터 수동 제어 · 위험 모드 전환/해제 수행
- 탭 5개 구성 — 모니터링 · 이벤트로그 · 그래프 · 평면도 · 도움말

---

## ⚙️ 동작

### 화면 구성

로그인 후 상단 메뉴로 5개 탭 전환. 공장(A~D)은 상단 버튼으로 별도 전환.

| 탭 | 내용 |
| --- | --- |
| 🎥 모니터링 | 카메라 4채널 실시간 영상 + 감지 박스 · 감시 제외 영역 설정 · 센서 수치 · 액추에이터 수동 제어 · 위험 모드 전환/해제 |
| 📋 이벤트로그 | 서버 기록 조회 목록 + 상세 패널. 날짜 · 구역 · 위험도 · 키워드 필터 |
| 📈 그래프 | 가스 · 연기 농도 추이. 기간(10분 / 1시간 / 6시간 / 하루) 선택, 경고 · 위험 발생 시점 마커 |
| 🗺 평면도 | 대피경로 지도. 전광판 클릭 시 각 출구까지의 경로 표시 |
| ❓ 도움말 | 화면별 사용법 + 실제 UI 를 재현한 미리보기 |

- 실제 센서 · 카메라 하드웨어는 **A공장에만** 연결 — B~D공장은 화면 확인용 시뮬레이션 값

### 서버 연동

- 주소는 `src/core/ServerConfig.h` 한 곳에서 관리 — 라즈베리파이 IP 가 바뀌면 여기만 수정
- 줄 단위 JSON(`\n` 구분)으로 통신

| 방향 | 메시지 |
| --- | --- |
| 수신 | 센서값 · 감지 결과 · 액추에이터 상태 · 전광판 상태 · 제어 응답 · 비상 응답 · 제외 영역 응답 · 조회 결과 |
| 송신 | 수동 제어 · 비상 전환/해제 · 오탐 신고 · 제외 영역 설정 · 기록 조회 |

- 조회는 대상(이벤트 기록 / 센서 기록 / 제외 영역)을 지정하고 요청 번호로 응답을 매칭
- 제외 영역은 접속 직후 서버가 요청 번호 없이 먼저 보내주기도 함 (저장된 설정 복원용)

### 감시 제외 영역

- 채널별로 꼭짓점 4개짜리 다각형을 지정해 감지 대상에서 제외
- 화재 / 연기 감지를 따로 켜고 끌 수 있음
- 영상 위젯에서 편집한 영역을 서버로 전송 → 서버가 감지 박스와의 겹침(기준 0.5)으로 판단

### 카메라 영상

```
MediaMTX (:8554) ──▶ cam1 ~ cam4 ──▶ 채널별 재생 (인증 없음)
```

| 채널 | 감시 대상 |
| --- | --- |
| Ch.1 | 화재 감지 |
| Ch.2 | 환기팬 |
| Ch.3 | 가스 밸브 |
| Ch.4 | 사이렌 · 스피커 |

- MediaMTX 주소는 `MainWindow.cpp` 에 별도 상수로 분리 — 서버와 같은 파이지만 역할이 달라 분리

### TLS

- `ServerConfig.h` 의 스위치로 평문 / TLS 전환. 현재 TLS 사용
- 인증서는 SHA-256 지문을 고정 검증 — 서버 인증서를 새로 만들면 이 값도 같이 갱신 필요

> ⚠️ 서버도 `-DENABLE_TLS=ON` 으로 빌드돼 있어야 합니다. 한쪽만 켜면 연결되지 않습니다.

## 📁 주요 파일

| 경로 | 하는 일 |
| --- | --- |
| `dashboard_main.cpp` | 진입점 — 폰트 등록 · 로그인↔대시보드 전환 |
| `src/core/` | 셸 · 탭 전환 · 서버 신호 배선 · 공용 타입 · 접속 설정 |
| `src/pages/` | 탭별 화면 1개 = 파일 1개 |
| `src/widgets/` | 페이지가 조립해 쓰는 위젯 — 상태 패널 · 그래프 · 감지 오버레이 · 영역 편집 영상 · 경고 배너 |
| `src/network/` | 서버 소켓 통신 · RTSP 영상 재생 |
| `resources/` | 폰트(한화고딕 2종) · 로그인 배경 · 리소스 정의 |

- 화면 내용은 각 페이지 클래스가 소유하고, 셸은 탭 전환과 서버 신호 전달만 담당

## 🔧 빌드·실행

### 개발 환경

- Qt 6.5 이상 (현재 6.11.0 / `mingw_64` 키트로 빌드)
- MinGW (`C:\Qt\Tools\mingw1310_64`) — `dlltool` 이 있어야 함
- CMake 3.19 이상 (`C:\Qt\Tools\CMake_64`)
- VLC for Windows (64bit) — `libvlc.dll` 사용

### 빌드

Qt Creator 에서 `qt_client/CMakeLists.txt` 를 열어 빌드하거나, 커맨드라인에서:

```bash
cmake -S qt_client -B qt_client/build -G "MinGW Makefiles"
cmake --build qt_client/build
```

VLC 를 기본 경로(`C:/Program Files/VideoLAN/VLC`)가 아닌 곳에 설치했다면:

```bash
cmake -S qt_client -B qt_client/build -G "MinGW Makefiles" -DVLC_DIR="D:/VLC"
```

빌드 후 `libvlc.dll` / `libvlccore.dll` 은 실행파일 옆으로 자동 복사됩니다. plugins 폴더는
용량이 커서 복사하지 않고 `VLC_PLUGIN_PATH` 환경변수로 설치 경로를 그대로 가리킵니다.

<details>
<summary><b>libvlc 연동 방식</b> — 함수를 새로 쓸 때 반드시 확인</summary>

RTSP 저지연 재생에 libvlc 를 씁니다(`:network-caching=500`). 공식 SDK 를 받지 않고, 설치된
`libvlc.dll` 에서 필요한 함수만 뽑아 MinGW 임포트 라이브러리를 빌드 시점에 생성합니다
(CMakeLists.txt 의 `dlltool` 커스텀 커맨드). 헤더도 필요한 선언만 담은
`src/network/vlc/libvlc_min.h` 를 직접 유지합니다.

> ⚠️ **libvlc 함수를 새로 쓰려면 CMakeLists.txt 의 `file(WRITE ... EXPORTS ...)` 목록에
> 심볼 이름을 직접 추가해야 합니다.** 안 그러면 링크 에러가 납니다.

</details>

### 실행

서버(라즈베리파이)와 MediaMTX 가 먼저 떠 있어야 합니다.

- 로그인 — `admin` / `1234` (현재 클라이언트에 하드코딩, 서버 인증 미연동)
- 5회 실패 시 30초 잠금. 「자동 로그인」 체크 시 다음 실행부터 로그인 화면을 건너뜁니다
- 로그인 시 서버 연결을 먼저 확인하고, 실패하면 대시보드로 진입하지 않습니다

## 🛠 문제 해결

### 굵은 글씨가 적용되지 않음

- **증상** — `font-weight:bold` 를 줘도 글자가 굵어지지 않음
- **원인** — 한화고딕 기본(`06HanwhaGothicL`)과 굵게(`07HanwhaGothicEL`) 두 TTF 가
  **서로 다른 패밀리로 등록**되어, Qt 가 굵은 쪽을 자동으로 고르지 못함
- **조치** — 굵게 써야 하는 자리마다 스타일시트에 패밀리명을 명시적으로 함께 지정

```css
font-family: "hanwhaGothic EL";
```

### 남은 제약

| 항목 | 현재 상태 |
| --- | --- |
| 로그인 인증 | 서버 연동 없이 클라이언트 하드코딩 계정으로만 동작 |
| B~D 공장 | 실제 하드웨어는 A공장에만 연결, 나머지는 시뮬레이션 값 |
| 자동 재접속 | 미구현 — 서버를 껐다 켜면 Qt 를 다시 실행해야 함 |
