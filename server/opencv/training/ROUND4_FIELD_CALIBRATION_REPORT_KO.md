# 연기 감지 Round 4/4B 현장 보정 기록

## 수정 이유

Round 3 양성 박스가 연기뿐 아니라 흰 구조물, 노란 발연기와 ArUco 마커까지 포함해
정적인 구조물을 연기로 학습한 문제가 확인됐다. 2026-08-27 녹화 영상에서는 실제 연기가
약 28초부터 시작하지만, 기존 NCNN 모델이 그 이전에도 구조물 주변을 연기로 검출했다.

## 데이터 교정

- 기존 영상 3개와 2026-08-27 신규 영상 1개를 다시 검수했다.
- 양성 박스는 구조물과 발연기를 제외하고 보이는 연기 기둥만 감싸도록 다시 작성했다.
- 신규 영상의 0~27.5초를 무연기 하드 네거티브로 사용했다.
- 28~30초는 연기가 시작되지만 박스 경계가 불명확해 양성·음성 모두에서 제외했다.
- `연기3.mp4`는 학습에 넣지 않고 영상 단위 검증셋으로 유지했다.
- Round 4는 기존 일반 데이터 1,621장을 함께 학습했고, Round 4B는 교정된 현장 데이터로
  confidence를 재보정했다.

## 학습 환경

- Google Colab NVIDIA Tesla T4
- Ultralytics 8.4.128, YOLOv8n
- 입력/NCNN export: 416x256
- 최종 모델: `smoke_yolov8n_round4b_field_calibrated_20260827_416x256_ncnn_model`
- 최종 런타임 confidence: `0.60`
- 확인 hit: 1회
- 마지막 검출 유지: 5초

## 최종 NCNN 프레임 검증

confidence 0.60, 0.5초 간격으로 실제 NCNN export를 실행했다.

| 검증 구간 | 결과 |
|---|---:|
| 신규 영상 무연기 0~27.0초 | 오탐 0/55 |
| 신규 영상 약 27.5초 | 1/1 검출(사용자 확인 시작 시점 약 28초) |
| 신규 영상 육안 식별 가능 연기 30.5~47.5초 | 23/35 검출 |
| 완전 홀드아웃 `연기3.mp4` 연기 구간 | 7/7 검출 |
| 홀드아웃 영상 사전 무연기 구간 | 오탐 0/49 |
| 홀드아웃 영상 사후 무연기 구간 | 오탐 0/7 |

1초 추론 주기, 1-hit 표시와 5초 유지 설정이므로 신규 영상에서는 약 27.5초 검출이
옅은 초기 구간을 덮고, 이후 가시 연기 검출이 경보를 갱신한다.

## 제한 사항

Round 4B는 현재 카메라 각도와 미니어처 세트에 맞춘 현장 특화 모델이다. 일반 검증셋에서는
confidence 0.60에서 smoke recall이 낮으므로, 다양한 장소에 그대로 적용하는 범용 모델로
주장하지 않는다. 카메라 위치나 배경을 바꾸면 해당 환경의 무연기 하드 네거티브와 실제 연기
영상을 추가해 다시 보정해야 한다.
