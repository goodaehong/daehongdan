# roi — 감지 제외 영역

## 📌 개요

- Qt 에서 지정한 영역을 감지에서 제외
- 화재 · 연기에 각각 다르게 적용 가능
- 서버 재시작 후에도 유지

---

## ⚙️ 동작

```
Qt 꼭짓점 좌표 ──▶ 검증 ──▶ roi_config.json 저장 ──▶ 카메라 워커가 반영
                                                    (버전 변화 감지)
```

**왜 필요한가** — 공장 모형의 회색 벽이 연기로 오인되는 등, 특정 구역을 빼야 하는 경우가
있습니다. 현장마다 다르고 재시작 후에도 남아야 해서 파일로 저장합니다.

**화재/연기를 나눠 적용합니다** (`applyTo`). 연기만 오탐이 나는 구역에서 화재 감지까지
죽이면 안 되기 때문입니다.

**카메라 워커는 매 프레임 확인하지 않습니다.** 평소엔 정수 하나(버전)만 읽고 지나가고,
값이 바뀐 순간에만 설정을 다시 읽습니다. 화재·연기 엔진이 각각 설정을 받으므로 둘 다 갱신합니다.

**적용 시점에 로그가 남습니다.**

```
[ROI] cam2 적용 — 화재 1개, 연기 0개
```

## 📁 주요 파일

| 파일 | 역할 |
| --- | --- |
| `roi_store.cpp/h` | 수신 · 검증 · 저장 · 복원 · 버전 관리 |
| `roi_config.json` | 현장별 설정 — 실행 중 생성, 커밋 안 함 |
