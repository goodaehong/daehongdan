# roi — 감지 제외 영역

## 📌 개요

- Qt 에서 지정한 영역을 감지에서 제외
- 화재 · 연기에 각각 다르게 적용
- 서버 재시작 후에도 유지

---

## ⚙️ 동작

```
Qt 꼭짓점 좌표 ──▶ 검증 ──▶ 설정 파일 저장 ──▶ 카메라 워커가 반영
```

### 왜 필요한가

- 공장 모형의 회색 벽이 연기로 오인되는 등, 특정 구역을 빼야 하는 경우 발생
- 현장마다 다르고 재시작 후에도 남아야 함 → 파일로 저장

### 화재/연기를 나눠 적용

| 설정 | 적용 대상 |
| --- | --- |
| 화재 전용 | 화재 감지만 제외 |
| 연기 전용 | 연기 감지만 제외 |
| 둘 다 | 양쪽 제외 |

- 연기만 오탐이 나는 구역에서 화재 감지까지 죽이면 안 되기 때문

### 매 프레임 파일을 읽지 않음

- 평소엔 정수 하나(버전)만 확인하고 지나감
- 값이 바뀐 순간에만 설정을 다시 읽음
- 화재·연기 엔진이 각각 설정을 받으므로 둘 다 갱신

적용 시점 로그

```
[ROI] cam2 적용 — 화재 1개, 연기 0개
```

## 📁 주요 파일

| 파일 | 하는 일 |
| --- | --- |
| `roi_store.cpp/h` | 수신 · 검증 · 저장 · 복원 · 버전 관리 |
| `roi_config.json` | 현장별 설정 — 실행 중 생성, 커밋 안 함 |

---

## 🔧 빌드·실행

ROI 코드는 서버 빌드에 포함되므로 별도 빌드는 필요 없습니다.

```bash
cmake -S server -B server/build
cmake --build server/build -j4
```

- Qt 모니터링 화면에서 채널과 적용 대상(화재·연기)을 선택한 뒤 영역을 저장
- 서버는 `ROI_CONFIG_PATH`가 가리키는 JSON에 저장하고 해당 채널 워커에 즉시 반영
- 서버는 점 3개 이상의 다각형을 처리하며, 현재 Qt 편집 화면은 꼭짓점 4개 영역을 전송

---

## 🛠 문제 해결

| 증상 | 확인할 것 |
| --- | --- |
| 영역 저장이 거부됨 | 좌표 형식과 꼭짓점 수(최소 3개), 채널 번호 확인 |
| 박스가 계속 표시됨 | 화재/연기 적용 대상과 `enabled`, 겹침 기준 `0.5` 확인 |
| 재시작 후 영역이 사라짐 | `ROI_CONFIG_PATH`와 설정 파일 쓰기 권한 확인 |
| 다른 해상도에서 위치가 어긋남 | 좌표가 원본 프레임 기준 `0~1` 비율인지 확인 |
