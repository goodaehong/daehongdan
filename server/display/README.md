# display — 전광판 (STM32 LED 매트릭스)

## 📌 개요

- STM32 전광판 보드에 UART 로 화면 갱신 · 대피 화면 전환 명령 전송
- 평상 화면(가스 농도 · 온습도 · 표정)과 대피 화면(화재 / 가스) 두 가지
- mock / 실물을 빌드 옵션으로 교체

---

## ⚙️ 동작

| 시점 | 보내는 것 | 명령 | 주기 |
| --- | --- | --- | --- |
| 평상시 | 가스 농도 · 온습도 · 표시 단계 | `0x80` UPDATE | 1초 |
| 위험 진입 | 재난 종류 · 구역 | `0x90` ALERT | 1회 |
| 〃 | 화재 위치 | `0xB2` EVAC_FIRES | 좌표 변경 시 |
| 〃 | 대피경로 | `0xB1` EVAC_PATH | 좌표 변경 시 |
| 해제 | 평상 복귀 | `0xA0` CLEAR | 1회 |

### 판단 계층을 안 받음

| 받는 것 | 안 받는 것 |
| --- | --- |
| 화면에 띄울 값 · 재난 종류 | 판정 결과 타입 |

- 판정 구조가 바뀌어도 이 모듈은 그대로

### 어디까지 이 모듈이 정하는가

| 이 모듈이 처리 | 밖에서 정해 넘김 |
| --- | --- |
| 가스 4자리 클램프 | 표시 단계 |
| 실수 → 정수 반올림 | 재난 종류 판별 |
| 시각 조회 | |

- 화면 표현을 바꿔도 호출부를 안 건드림
- 표시 단계·재난 종류는 **판단 기준**이라 판정 쪽 소관

### 표정·그래프는 가스 농도로만 결정

- 화재·연기만 감지되고 가스가 정상인데도 표정이 빨갛게 뜨던 문제를 해결
- 화재·연기 경보는 대피 화면 전환이 따로 처리

### 대피경로는 좌표가 바뀔 때만 전송

- 매초 보내면 출구 수만큼 패킷이 반복되고 화면도 깜빡임

## 🔧 빌드·실행

```bash
cmake -S server -B server/build -DUSE_MOCK_DISPLAY=ON   # mock
```

- 장치 경로는 `STM_DISPLAY_DEVICE` 로 주입 (기본 `/dev/stm_display`)
- 패킷 조립은 `drivers/stm_uart_display/stm_display_protocol.c` 를 링크해서 씁니다

## 🛠 문제 해결

### 연달아 쏘면 패킷이 깨짐

- **원인** — STM32 수신 버퍼 초과
- **조치** — 패킷 사이 20ms 대기 삽입

### 전송량 상한

| 대상 | 상한 | 초과 시 |
| --- | --- | --- |
| 경로 웨이포인트 | 30개 | 전송 안 하고 실패 반환 |
| 화재 위치 | 6곳 | 〃 |

### 응답 없음

- 링크 상태가 `false` — 보드 전원 · UART 연결 확인
