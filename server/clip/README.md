# clip — 이벤트 클립 자동 저장

## 📌 개요

- 경보 발생 시 전후 영상을 mp4 로 자동 저장
- 직전 3초 + 이후 10초 = **13초**
- Qt 가 이벤트 로그에서 재생

---

## ⚙️ 동작

```
평상시  카메라 워커 ──▶ 링 버퍼 (직전 3초, 30프레임)
경보    ClipRecorder_Start() ──▶ 링 버퍼 + 이후 10초 ──▶ mp4 인코딩 (별도 스레드)
완료    콜백 ──▶ DB 의 clip_path 갱신
```

**직전 구간을 미리 들고 있는 이유** — 경보 이후만 녹화하면 정작 원인이 되는 장면이 빠집니다.
이벤트는 예고 없이 터지므로 평소에도 계속 버퍼에 쌓아둡니다.

**인코딩은 별도 스레드에서 합니다.** 13초 뒤에 저장이 끝나므로, 제어 루프가 기다리지 않고
완료 시점에 콜백으로 DB 경로만 채웁니다.

**코덱은 `avc1`(H.264) 우선입니다.** Qt 의 Windows 디코더가 확실히 재생하고 용량도 절반입니다.
없는 빌드가 많아 실패 시 `mp4v` 로 폴백합니다.

- 해상도 640×360 · 10fps — 감지 프로파일에 맞춤
- 카메라가 끊겨도 5초 지나면 모인 프레임만으로 저장
