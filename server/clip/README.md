# clip — 이벤트 영상 클립 자동 저장

## 📌 개요

- 경보 발생 시 전후 영상을 mp4 로 자동 저장
- 직전 3초 + 이후 10초 = **13초**
- Qt 가 이벤트 로그에서 재생

---

## ⚙️ 동작

```
평상시  카메라 워커 ──▶ 링 버퍼 (직전 3초 · 30프레임)
경보    링 버퍼 + 이후 10초 ──▶ mp4 인코딩 (별도 스레드)
완료    콜백 ──▶ DB 의 클립 경로 갱신
```

### 직전 구간을 미리 들고 있는 이유

- 경보 이후만 녹화하면 정작 원인이 되는 장면이 빠짐
- 이벤트는 예고 없이 발생 → 평소에도 계속 버퍼에 쌓아둠

### 인코딩을 분리한 이유

- 저장 완료까지 13초 — 제어 루프가 기다릴 수 없음
- 완료 시점에 콜백으로 DB 경로만 채움

### 저장 규격

| 항목 | 값 | 이유 |
| --- | --- | --- |
| 해상도 | 640×360 | 감지 프로파일과 동일 |
| 프레임 | 10fps | 〃 |
| 코덱 | `avc1`(H.264) 우선 | Qt 의 Windows 디코더가 확실히 재생 · 용량 절반 |
| 폴백 | `mp4v` | `avc1` 이 없는 빌드가 많음 |

- 카메라가 끊겨도 5초 지나면 모인 프레임만으로 저장
