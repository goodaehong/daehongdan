# floormap — 평면도 등록 · 대피경로 변환

## 📌 개요

- Qt 가 올린 평면도 PNG 를 저장하고 대피경로로 변환
- 변환 결과를 보관했다가 Qt 응답 · 전광판 전송에 사용
- 화재 발생 시 경로 재계산

---

## ⚙️ 동작

```
Qt (base64 PNG) ──▶ 검증 ──▶ 저장 ──▶ 경로 계산 호출
                                        ├── Qt 응답용 결과
                                        └── 전광판 전송용 결과
```

### 알고리즘을 갖지 않음

- 이 모듈은 호출 · 보관 · 전달만 담당
- 계산은 `evac_map_tools` 담당 → 알고리즘이 바뀌어도 이 모듈은 그대로

### 화재가 있으면 다시 계산

| 상황 | 사용하는 경로 |
| --- | --- |
| 화재 없음 | 등록 시 계산해둔 기본 경로 |
| 화재 있음 | 화재 좌표를 넣어 재계산한 경로 |
| 위험 해제 | 기본 경로로 복귀 |
| 재계산 실패 | 기본 경로로 폴백 |

- 등록 시점 경로는 화재를 그대로 통과하므로 재계산 필요
- 재계산 결과는 **전광판 전송용 일회성** — Qt 응답용은 화재 없는 기준을 유지
- 재계산은 잠금 밖에서 수행 — Qt 요청을 막지 않으려고

### 경로 결과 형식

- 평탄 배열로 전달 — `(전광판1→출구1,2,…)`, `(전광판2→…)` 순서
- 도달 불가 경로도 빈 행으로 자리를 지킴

## 📁 주요 파일

| 파일 | 하는 일 |
| --- | --- |
| `floormap_store.cpp/h` | 전송 데이터 해석 · PNG 검증 · 변환 호출 · 저장 · 복원 |
| `uploaded_map.png` | 등록된 평면도 — 실행 중 생성, 커밋 안 함 |
| `floor_map.json` | 변환 결과 — 실행 중 생성, 커밋 안 함 |
