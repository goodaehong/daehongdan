# floormap — 평면도 등록 · 대피경로 변환

## 📌 개요

- Qt 가 올린 평면도 PNG 를 저장하고 대피경로로 변환
- 변환 결과를 보관했다가 Qt 응답 · 전광판 전송에 사용
- 화재 발생 시 경로 재계산

---

## ⚙️ 동작

```
Qt (base64 PNG) ──▶ 검증 ──▶ 저장 ──▶ EvacPlanner 호출
                                        ├── Qt 응답용 JSON
                                        └── 전광판 전송용 숫자
```

**서버는 알고리즘을 갖지 않습니다.** 호출·보관·전달만 합니다. 경로 계산은
`evac_map_tools/EvacPlanner` 담당이라, 알고리즘이 바뀌어도 이 모듈은 그대로입니다.

**화재가 있으면 경로를 다시 계산합니다.** 등록 시점에 계산해둔 경로는 화재를 그대로
통과하므로, 화재 좌표를 넣어 `processFloorPlan()` 을 다시 호출합니다.

- `fires` 가 비면 저장된 기본 경로를 그대로 사용 (위험 해제 시 원래 경로 복귀)
- 재계산 결과는 전광판 전송용 일회성 — **Qt 응답용 결과는 화재 없는 기준을 유지**합니다
- 재계산은 뮤텍스 밖에서 수행 (Qt 요청을 막지 않으려고)
- 실패 시 기본 경로로 폴백

**경로는 평탄 배열로 옵니다.** `(전광판1→출구1,2,…)`, `(전광판2→…)` 순서이고,
도달 불가 경로도 빈 행으로 자리를 지킵니다.

---

## 📁 주요 파일

| 파일 | 역할 |
| --- | --- |
| `floormap_store.cpp/h` | base64 디코딩 · PNG 검증 · 변환 호출 · 저장 · 복원 |
| `uploaded_map.png` | 등록된 평면도 — 실행 중 생성, 커밋 안 함 |
| `floor_map.json` | 변환 결과 — 실행 중 생성, 커밋 안 함 |
